# PC Builder

Клиент-серверное веб-приложение для автоматизированного подбора компьютерных комплектующих с проверкой совместимости. Позволяет собирать конфигурации ПК, автоматически фильтрует совместимые компоненты, выполняет парсинг цен с сайтов магазинов и сохраняет сборки в личном кабинете.

## 📥 Исходный код

Исходный код проекта доступен в репозитории:
- **Backend (серверная часть)**: `PcBuilder.Api` — ASP.NET Core Web API на C#
- **Frontend (клиентская часть)**: `PcBuilder.Api/wwwroot` — SPA на HTML/CSS/JavaScript
- **Общие модели**: `PcBuilder.Core` — библиотека классов (Entity Framework, DTO)
- **Тесты**: `PcBuilder.Tests` — модульные тесты (xUnit, Moq)

## 🚀 Установка и запуск

### Windows (установщик)
1. Скачайте [PCBuilder_Setup.exe]([https://github.com/username/PcBuilder/releases/latest](https://github.com/TimonKryt/PcBuilder/releases/download/v1.0/PCBuilder_Setup.exe))
2. Запустите установщик и следуйте инструкциям
3. После установки запустите приложение через ярлык на рабочем столе
4. Приложение откроется в браузере по умолчанию

### Windows (портативная версия)
1. Скачайте [PCBuilder_Portable.zip](https://github.com/username/PcBuilder/releases/latest)
2. Распакуйте архив в любую папку
3. Запустите `PcBuilder.Api.exe`
4. Откройте браузер и перейдите на `http://localhost:5000`

### Android / iOS (PWA)
1. Откройте сайт приложения в браузере (Chrome для Android, Safari для iOS)
2. Нажмите «Установить приложение» (Android) или «На экран Домой» (iOS)
3. Приложение появится на рабочем столе и будет работать как нативное

## 🔑 Начало работы

При первом запуске приложения автоматически создаётся база данных с тестовыми товарами (17 комплектующих) и правилами совместимости.

**Регистрация:**
1. Нажмите кнопку «Регистрация»
2. Введите email, имя пользователя и пароль (минимум 6 символов)
3. После успешной регистрации вы автоматически войдёте в систему

- Автоматическая фильтрация совместимых компонентов при сборке
- Проверка совместимости всей сборки

- Загрузка сохранённых сборок

## 📱 Функционал приложения

### Конфигуратор ПК
- Выбор типа комплектующего из левой панели
- Отображение доступных товаров в правой панели
- Автоматическая фильтрация совместимых компонентов
- Визуализация текущей сборки в центральной панели
- Расчёт итоговой стоимости в реальном времени

### Проверка совместимости
- Автоматическая проверка по правилам:
  - Совпадение сокета (CPU ↔ Motherboard)
  - Достаточность мощности БП (TDP < Wattage)
  - Совместимость форм-фактора (Motherboard ↔ Case)
  - Исключение несовместимых чипсетов
- Отображение предупреждений при конфликтах

### Личный кабинет
- Сохранение сборок с названием
- Просмотр списка сохранённых сборок
- Загрузка сборки в конфигуратор
- Отображение даты создания и стоимости

### Парсинг цен (Администратор)
- Запуск парсинга через API
- Поддержка магазинов: DNS, Ситилинк, М.Видео
- Обработка ошибок доступа (403/401)
- Генерация тестовых данных при недоступности сайтов
- Логирование результатов в консоль

## 🔄 API эндпоинты

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| POST | `/api/auth/register` | Регистрация пользователя |
| POST | `/api/auth/login` | Вход в систему |
| GET | `/api/auth/me` | Профиль текущего пользователя |
| GET | `/api/builder/component-types` | Список типов комплектующих |
| GET | `/api/builder/products/{type}` | Товары по типу |
| GET | `/api/builder/compatible/{id}/{type}` | Совместимые товары |
| POST | `/api/builder/builds` | Сохранение сборки |
| GET | `/api/builder/builds` | Сборки пользователя |
| GET | `/api/builder/builds/{id}` | Сборка по ID |
| POST | `/api/builder/check-compatibility` | Проверка совместимости |
| POST | `/api/parsing/start` | Запуск парсинга |
